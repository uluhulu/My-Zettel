## 🌐 1. IP-адрес

**IP-адрес (Internet Protocol address)** — это уникальный числовой идентификатор устройства в сети, необходимый для обмена данными.

### Форматы:

- **IPv4:** 32-битный адрес, записывается в виде четырёх чисел (0–255), например:  
    `192.168.1.10`
    
- **IPv6:** 128-битный адрес (используется из-за нехватки IPv4), например:  
    `fe80::1a2b:3c4d:5e6f:7g8h`
    

---

## 🧩 2. Маска подсети (Subnet Mask)

Маска подсети определяет, **какая часть IP-адреса — это сеть**, а **какая — устройство (хост)**.

Например:

- IP: `192.168.1.10`
    
- Маска: `255.255.255.0`  
    → первые три октета (`192.168.1`) — сеть,  
    последний (`.10`) — устройство.
    

> Упрощённо: маска помогает разделить большую сеть на маленькие подсети и определить, какие компьютеры находятся в одной локальной сети.

---

## 🌉 3. Шлюз по умолчанию (Default Gateway)

Это **устройство, через которое компьютер выходит за пределы своей локальной сети** (обычно — роутер).

- Пример:  
    IP компьютера — `192.168.1.10`  
    Шлюз — `192.168.1.1`  
    → всё, что не в сети `192.168.1.x`, отправляется на шлюз.
    

---

## 🔡 4. DNS (Domain Name System)

DNS — это **система, которая переводит доменные имена в IP-адреса**.

Пример:

- Вы вводите в браузере: `www.google.com`
    
- DNS-сервер возвращает IP: `142.250.74.14`
    
- Компьютер соединяется с этим адресом.
    

> То есть DNS — это «телефонная книга» Интернета.

---

## ⚙️ 5. Статическая и динамическая адресация

|Тип адресации|Описание|Преимущества|Недостатки|
|---|---|---|---|
|**Статическая**|IP-адрес задаётся вручную пользователем или администратором.|Постоянный IP, удобно для серверов.|Нужно настраивать вручную, риск конфликтов IP.|
|**Динамическая**|IP назначается автоматически с помощью DHCP.|Просто, быстро, нет конфликтов.|IP может меняться при каждом подключении.|

---

## 🔁 6. DHCP (Dynamic Host Configuration Protocol)

**DHCP** — это протокол, который **автоматически выдаёт IP-адреса и сетевые параметры** устройствам в сети.

### Как работает DHCP:

1. Устройство подключается к сети и отправляет запрос: _«Дайте мне IP!»_
    
2. DHCP-сервер предлагает свободный IP-адрес.
    
3. Устройство получает IP, маску подсети, шлюз, DNS.
    
4. Адрес выдается **на время (lease time)**, после чего может обновиться.
    

> 💡 Пример:  
> Ваш телефон подключается к Wi-Fi, и роутер (в роли DHCP-сервера) автоматически выдаёт ему IP: `192.168.0.15`.

---

## 🔗 7. Link-local адрес

Это **специальный IP-адрес**, который устройство назначает себе **автоматически**, если не получило адрес от DHCP.

- Диапазон для **IPv4:** `169.254.0.0 – 169.254.255.255`
    
- Диапазон для **IPv6:** начинается с `fe80::`
    

> Используется для локального взаимодействия между устройствами без роутера или DHCP-сервера.  
> Пример: два ноутбука подключены напрямую кабелем — они могут обмениваться файлами через link-local адреса.

---

## 🧠 Итоговая схема:

```
IP-адрес:        192.168.1.10     ← идентификатор устройства
Маска подсети:   255.255.255.0     ← определяет границы сети
Шлюз:            192.168.1.1       ← выход в Интернет
DNS:             8.8.8.8           ← преобразует имена сайтов в IP
Адресация:       Статическая / Динамическая (через DHCP)
Link-local:      169.254.x.x       ← при отсутствии DHCP
```
