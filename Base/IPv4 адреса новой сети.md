Отлично, давай разберём пошагово, как получили эти адреса для подсети.

---

## Дано

- IP узла: **172.16.70.100**
    
- Исходная маска: **255.255.0.0 (/16)**
    
- Новая маска: **255.255.240.0 (/20)**
    

---

## 1️⃣ Определяем сетевой адрес подсети

**Шаг 1: Разберём маску /20**

- /20 → первые 20 бит — сеть, оставшиеся 12 бит — хосты.
    
- Маска в двоичном виде:
    

```
11111111.11111111.11110000.00000000
```

- 20 единиц → первые два октета полностью = сеть,
    
- третий октет частично (первые 4 бита = сеть, последние 4 бита = хост),
    
- четвёртый октет полностью для хостов.
    

---

**Шаг 2: Побитовое И (IP & маска)**

- IP узла 172.16.70.100
    

Разбиваем третий октет на блоки, по шагу 16 (четыре бита для подсети → шаг = 2^(8−4) = 16):

- Возможные блоки третьего октета: 0,16,32,48,64,80,96,…
    
- IP = 70 → попадает в блок **64–79**
    

Следовательно, **сетевой адрес подсети** = **172.16.64.0**

---

## 2️⃣ Определяем первый хост

- Первый хост = сетевой адрес + 1  
    [  
    172.16.64.0 + 1 = 172.16.64.1  
    ]
    

---

## 3️⃣ Определяем последний хост и широковещательный адрес

- Узловая часть = 12 бит (32 − 20 = 12)
    
- В третьем октете используется 4 бита для подсети → остаётся 4 бита для хостов третьего октета + 8 бит четвёртого октета = 12 бит
    

**Шаг 1:** диапазон третьего октета: 64–79 (это блок подсети)

- Третий октет последнего хоста = 79
    
- Четвёртый октет: последний хост = 254 (последний адрес до broadcast)
    

**Широковещательный адрес:**

- Последний адрес в подсети = **все биты узловой части = 1**
    
- Четвёртый октет = 255 → 172.16.79.255
    

---

## 🔹 Итог:

|Параметр|Адрес|
|---|---|
|IPv4-адрес подсети|172.16.64.0|
|Первый хост|172.16.64.1|
|Последний хост|172.16.79.254|
|Широковещательный адрес|172.16.79.255|

---

💡 **Ключевые моменты:**

1. Сетевой адрес = IP узла & маска новой подсети
    
2. Первый хост = сетевой адрес + 1
    
3. Последний хост = broadcast − 1
    
4. Broadcast = все биты узловой части = 1
