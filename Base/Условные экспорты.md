## Как работают условные импорты

### **Логика работы:**

1. **По умолчанию**: экспортируется `db_executor_stub.dart`
2. **Если доступна библиотека `dart:ffi`**: экспортируется `db_executor_native.dart`
3. **Если доступна библиотека `dart:html`**: экспортируется `db_executor_web.dart`

## Платформенная специфика

### **`dart:ffi` (Foreign Function Interface)**

- Доступна на: **мобильных платформах** (Android, iOS) и **десктопе** (Windows, macOS, Linux)
- Позволяет вызывать нативный C/C++ код
- Используется для работы с SQLite через нативные библиотеки

### **`dart:html`**

- Доступна только в **браузере/web**
- Предоставляет доступ к DOM и Web APIs
- Используется для работы с IndexedDB или Web SQL

### **Stub (заглушка)**

- Используется как fallback
- Обычно содержит базовые интерфейсы или throws UnimplementedError
