`display: flex;` превращает элемент в flex-контейнер, что позволяет:

- **Выстраивать дочерние элементы в ряд** (по умолчанию горизонтально)
- **Контролировать выравнивание** элементов с помощью свойств как `justify-content`, `align-items`
- **Легко управлять расстояниями** между элементами с помощью `gap`
- **Создавать адаптивные макеты** без использования float или position

В вашем коде `display: flex` используется в:

- `.container__header` - для размещения логотипа и меню в ряд
- `.header-links` - для горизонтального размещения навигации и телефона
- `.header-links nav` - для размещения ссылок меню в ряд
- `.header-phone` - для вертикального размещения элементов (с `flex-direction: column`)
