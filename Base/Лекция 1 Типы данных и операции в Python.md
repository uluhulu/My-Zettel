Объект имеющий определенный тип обладает определенным набором свойств.

Часто для простаты говорят **тип данных имеет свойство**. 

Мы будем иметь дело со след свойствами объектов :
- свойство быть изменямым (mutable) или неизменяемым (immutable)
- свойство быть перечислимым (enumerable) так же используется тип "итерируемый тип"
- свойство быть упорядоченным (sequence) или, другими словами, свойство быть последовательностью
      последовательность это итерируемый тип, дополнительно обладающий свойством упорядоченности. 

Категории типов данных :
Встроенные типы данных
- Встроенные типы данных не нужно импортировать явно
- Среди встроенных типов данных есть как простые так и композитные

Типы данных, определяемый пользователем (user-defined) :
- Класс созданный программистом становится типом данных для производимых для него объектов
- Вместе с интепритатором появляется стандартная библиотека языка (Это означает, что **в дополнение к базовым типам** (например, числа, строки, списки) язык программирования поставляется **с набором дополнительных модулей и классов**, которые уже написаны другими программистами (создателями языка).  
То есть, **они не встроены в ядро языка**, но **идут в комплекте**.)
- Типы данных включенные в стандартную библиотеку можно рассматривать как типы данных определенные пользователем(Типы, которые входят в стандартную библиотеку (например, `datetime.date`), **тоже созданы программистами** — просто не _нами_, а _разработчиками языка_.  
То есть, **они технически такие же классы, как и наши**, просто входят в «официальный набор».)

Встроенный типы данных : 
- числа
- логический тип данных (bool True False)
- Тип NoneType имеющий единственное значение None (индикатор отсутствия информации, аналогичен null)
- Композитные типы данных
Коллекции это композитные типы, которые можно рассматривать как совокупность объектов. 
Последовательности символов или байт 
- Строки (неизменяемые последовательности символов )
- Байты (неизменяемые последовательности байт)
- Байтовые массивы (изменяемые последовательности байт)
Все элементы последовательности символов или байт имеют один и тот же тип (
- В строке **все элементы — символы (строки длиной 1)**.
    
- В `bytes` и `bytearray` **все элементы — байты (числа от 0 до 255)**.  
    Нельзя в одну и ту же байтовую последовательность добавить, например, строку — только байты.
)
Другие встроенные коллекции : 
- Списки
- Кортежи
- Словари и множества (в других языках словарь это ассоциативный массив, хэш или map)
Объекты имеющие тип класса созданного пользователем также могут быть коллекциями

Литерал это буквальная запись содержимого объекта 
- Числовые литералы
- Текстовые литералы

Числа : 
- Целые числа, разрядность не ограничена
- Числа с плавающей запятой
- Числа с фиксированной запятой (класс Decimal)
- Рациональные числа или дроби (класс Fraction)
- Комплексные числв 

Операторы и операции :
- инструкция это одно из элементарных действия, последовательность которых состоявляет программу
- операция это действие над объектоми или объектом, совершаемое при вычислении выражения
- оператор это символ или зарезервированное слово для обозначения операции
- большая часть операторов языка двуместные :
-     a + b  # сложение, коммутативная операция
-     a - b # вычитание, некоммутативная операция 
-  одноместные операторы, например - х # унарный минус
- трехместный оператор x if y else z аналогичен оператору ?: языка C
