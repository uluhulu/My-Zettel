# Методичка: Типы **Infinity** и **NaN** в JavaScript

---

## 1. Что такое **Infinity**?

- **Infinity** — специальное числовое значение, представляющее бесконечность.
    
- Используется для обозначения чисел, которые превышают максимально возможное число в JavaScript.
    

### Как получается **Infinity**?

- Деление положительного числа на 0:
    
    ```js
    console.log(1 / 0);  // Infinity
    ```
    
- Очень большие числа, выходящие за пределы диапазона:
    
    ```js
    console.log(1e308 * 10);  // Infinity
    ```
    

### Свойства **Infinity**:

- Это значение типа **number**:
    
    ```js
    console.log(typeof Infinity);  // "number"
    ```
    
- Есть также **-Infinity** — отрицательная бесконечность.
    

### Сравнения с **Infinity**:

```js
console.log(Infinity > 1000000);  // true
console.log(-Infinity < -1000000); // true
```

---

## 2. Что такое **NaN**?

- **NaN** — сокращение от "Not-a-Number" (не число).
    
- Используется для обозначения результата математической операции, которая не имеет смысла или не может быть вычислена как число.
    

### Когда появляется **NaN**?

- При ошибочных математических операциях:
    
    ```js
    console.log(0 / 0);       // NaN
    console.log("abc" * 10);  // NaN
    console.log(Math.sqrt(-1)); // NaN
    ```
    

### Свойства **NaN**:

- Тип — **number**:
    
    ```js
    console.log(typeof NaN);  // "number"
    ```
    
- **NaN** не равен ничему, даже самому себе:
    
    ```js
    console.log(NaN === NaN); // false
    ```
    

### Как проверить на **NaN**?

- Используйте функцию `isNaN()` или лучше `Number.isNaN()`:
    
    ```js
    isNaN(NaN);          // true
    Number.isNaN(NaN);   // true
    
    isNaN("text");       // true (нестрогая проверка)
    Number.isNaN("text");// false (строгая проверка)
    ```
    

---

## 3. Итоги

| Значение    | Тип    | Описание                                       | Пример                 |
| ----------- | ------ | ---------------------------------------------- | ---------------------- |
| `Infinity`  | number | Положительная бесконечность                    | `1 / 0` → `Infinity`   |
| `-Infinity` | number | Отрицательная бесконечность                    | `-1 / 0` → `-Infinity` |
| `NaN`       | number | Результат нечисловой или некорректной операции | `"abc" * 10` → `NaN`   |
