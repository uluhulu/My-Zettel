### Фабричный метод

Ключевое слово factory является синтаксическим сахаром для выражения чего-то. Это базовый паттерн, который называется фабричным методом или шаблонным фабричным методом. 

По сути, конструктор по умолчанию - это не что иное, как static метод, определенный в классе, возвращаемый тип которого должен быть того же типа. Основным отличием по сравнению с "нормальной" static функцией в классе является невозможность изменения его возвращаемого вида. 

Основные преимущества использование паттерна фабрика :
- Ответственность за создание объекта лежит не внутри самого класса, а в отдельном классе (фабричный метод), который реализует интерфейс
- Создание объекта лишено гибкости, поскольку вы не можете изменить конкретный экземпляр объекта

Вывод : Его можно использовать для создания объектов, не раскрывая вызывающей стороне детали базовой реализации. 

### Типы конструкторов

В Dart есть порождающие и фабричные конструкторы, которые могут быть именованный или неименованные. 

Примером порождающего конструктора является конструктор по умолчанию, который создается автоматически для каждого класса. 

В документации в основном упоминаются три варианта использования factory конструктора:

- Возврат экземпляра из кэша
    
- Возвращает экземпляр подтипа
    
- Инициализация конечной переменной
#### Сложная инициализация final переменной 

Если у вас есть более сложная инициализация `final` переменной, которая не может быть обработана внутри списка инициализаторов. Для решения можно использовать `factory`конструктор. (Например fromJson)

Здесь инициализация переменной `color` требует некоторой логики. Поскольку необходимо выполнить несколько инструкций, это лучше сделать внутри конструктора `factory`.

### Разница между порождающим конструктором и factory конструктором

Порождающий конструктор класса всегда возвращает новый экземпляр класса.

factory конструктор связан с более слабыми ограничениями. Для конструктора factory достаточно что бы возвращаемый объект имел тот же тип или удовлетворял его интерфейсу. Это может быть новый экземпляр класса или существующий экземпляр класса. 

Фабрика может использовать поток управления , чтобы определить, какой объект возвращать, и поэтому должна использовать ключевое слово return.

Основные и незначительные различия : 

- Фабричный конструктор может вызвать другой констурктор если он не возвращает экземпляр напрямую.
- Фабричный конструкторам разрешено возвращать существующий объект.
- Фабричным конструкторам разрешено возвращать подкласс.
- Производный класс не может вызывать фабричный конструктор суперкласса. Как следствие, класс, предоставляющий исключительно фабричные конструкторы, не может быть расширен. 
- Порождающие конструткоры не могут устанавливать final свойства в теле конструктора. 
- Порождающие конструкторы могут быть const и не нуждаются в перенаправлении 
### Разница между static и factory

Каждый factory конструктор является технически static методом, но не каждый static метод является factory конструктором. Самое большое различие в том что в factory возвращаемый тип является типо текущего или производного классов, в то время как для статического метода вы можете указать любой возвращаемый тип. 

Все различия : 
- factory конструктор в отличие от static метода может возвращать только экземпляр текущего класса
- static метод может быть async. Поскольку factory конструкторам необходимо возвращать экземпляр текущего или подкласса, он не может вернуть Future.
- Фабричные конструкторы могут использовать специальный синтаксис для перенаправления
- Для фабричного конструктора не обязательно указывать общие параметры
- Фабричные конструкторы могут быть объявлены `const`
- Фабричный конструктор не может возвращать тип, допускающий значение null.
