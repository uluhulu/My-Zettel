Пакет **flutter_secure_storage** используется в Flutter для безопасного хранения данных на устройстве пользователя.

### Основное назначение:

- Хранение конфиденциальной информации, такой как **токены аутентификации**, **пароли**, **ключи шифрования** и другие чувствительные данные.
    
- Данные сохраняются в защищённом хранилище, которое использует нативные механизмы безопасности платформ:
    
    - На iOS — Keychain.
        
    - На Android — EncryptedSharedPreferences или Keystore.
        

### Почему это важно:

- Обычное локальное хранение (например, SharedPreferences) не обеспечивает необходимой безопасности.
    
- flutter_secure_storage шифрует данные и хранит их в системных защищённых хранилищах, что затрудняет доступ посторонних.
    

### Пример использования:

```dart
final storage = FlutterSecureStorage();

// Записать данные
await storage.write(key: 'token', value: 'my_secret_token');

// Прочитать данные
String? token = await storage.read(key: 'token');

// Удалить данные
await storage.delete(key: 'token');
```
