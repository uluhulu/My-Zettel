**`position: relative;`** - это CSS-свойство, которое устанавливает относительное позиционирование элемента.

## Что это означает:

- Элемент остается в **нормальном потоке документа** (не вырывается из него)
- Можно сдвигать элемент относительно его **первоначальной позиции** с помощью свойств `top`, `right`, `bottom`, `left`
- Место, которое элемент занимал изначально, **остается зарезервированным**
- Элемент становится **контекстом позиционирования** для дочерних элементов с `position: absolute`
