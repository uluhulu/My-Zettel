1.      Что такое класс File?
В Python под классом File обычно понимают файловый объект, который создается функцией open().
Файловый объект представляет открытый файл на диске и обеспечивает интерфейс для выполнения операций ввода-ввывода. 

Файловый объект инкапсулирует: 
- положение указателя внутри файла
- режим работы( чтение запись добавление и др)
- методы для обработки текстовых и бинарных данных

2.      Как осуществить открытие файла?

Открытие файла выполняется посредством встроенной функции :
open(filename, mode)
где:
- filename - путь к файлу 
- mode - строка, определяющая режим работы (`"r"`, `"w"`, `"a"`, `"rb"`, `"wb"` и др.).

3.      Перечислите методы класса для File ввода-вывода. 

Основные методы файловых объектов:
Методы чтения :
- read(size) - чтение указанного количества символов/байт (или всего файла)
- readline() - чтение одной строки
- readlines() - чтение всех строк с возвратом списка

Методы записи :
- write(string) - запись строки или байтового объекта
- writelines(list) - запись последовательности строк

4.      Как осуществляется взаимодействие с файловой системой?
Взаимодействие с файловой системой в Python выполняется через стандартные модули:

- **`os`** — низкоуровневые операции с каталогами и файлами (создание, удаление, получение информации);
    
- **`os.path`** — функции для работы с путями (получение расширений, объединение путей, проверка существования);
    
- **`shutil`** — высокоуровневые операции (копирование, перемещение, архивирование);
    
- **`pathlib`** — объектно-ориентированный интерфейс для работы с путями.

5.      Что такое модуль path? 

В контексте Python под модулем _path_ могут подразумеваться:
- os.path
Стандартный модуль, предоставляющий функции для манипуляций с файловыми путями:
- join(),
- basename(),
- dirname(),
- splitext(),

pathlib

Современный объектно-ориентированный подход к работе с путями
Предоставляет класс Path, инкапсулирующий путь в виде объекта и включающий методы для навигации, проверки и обработки файловых путей

6.      Расскажите про объекты и файловый ввод-вывод.

В Python файл представлен **объектом**, который создаётся вызовом функции `open()`.  
Файловый объект содержит:

- состояние (режим работы, позиция указателя, статус «открыт/закрыт»);
    
- методы для чтения и записи информации;
    
- встроенную буферизацию, обеспечивающую эффективный ввод-вывод.
    

Файловый ввод-вывод реализован в объектно-ориентированном стиле:  
все операции производятся через методы объекта файла, что обеспечивает удобство, безопасность и инкапсуляцию деталей взаимодействия с операционной системой.
