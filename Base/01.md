Отличные вопросы 👍 — это базовые, но очень важные понятия веб-разработки. Разберём всё по пунктам:

---

### 🧩 **1. Что такое HTML**

**HTML (HyperText Markup Language)** — это язык разметки гипертекста, с помощью которого создаются веб-страницы.  
Он определяет **структуру** содержимого страницы — где заголовки, абзацы, изображения, ссылки и т.д.

📘 Пример простейшей HTML-страницы:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый сайт.</p>
  </body>
</html>
```

---

### 🔖 **2. Что такое тег / атрибут / значение**

HTML строится из **тегов** — специальных «команд» в угловых скобках `< >`.

- **Тег** — элемент HTML, который обозначает, **что это за часть содержимого**.  
    Пример: `<p>` — абзац, `<h1>` — заголовок, `<img>` — изображение.
    
- **Атрибут** — дополнительная информация внутри тега, которая **уточняет его поведение**.  
    Пример:
    
    ```html
    <img src="cat.jpg" alt="Кот">
    ```
    
    Здесь:
    
    - `src` — **атрибут**, указывающий путь к изображению;
        
    - `"cat.jpg"` — **значение атрибута**;
        
    - `alt` — атрибут, задающий альтернативный текст.
        

🧠 Формат:

```html
<имя_тега атрибут="значение">Контент</имя_тега>
```

---

### 🏷️ **3. Для чего используется тег `<имя_тега>`**

Тег определяет **тип содержимого** и **его роль** на странице.  
Например:

- `<h1>` — главный заголовок страницы;
    
- `<p>` — абзац текста;
    
- `<a>` — ссылка;
    
- `<button>` — кнопка;
    
- `<img>` — изображение.
    

Таким образом, **теги сообщают браузеру, как отображать информацию** и какую она несёт смысловую нагрузку.

---

### 📜 **4. Зачем нужен `<!DOCTYPE>`**

`<!DOCTYPE html>` — это **объявление типа документа**.  
Оно указывает браузеру, **в какой версии HTML написана страница**.

Сегодня почти всегда используется:

```html
<!DOCTYPE html>
```

— что означает **HTML5**.  
Без него браузер может перейти в «режим совместимости» и неправильно интерпретировать стили или теги.

---

### 🔗 **5. Как отличить кнопку от ссылки**

Обе могут выглядеть похоже, но **служат разным целям**:

|Элемент|Тег|Назначение|Пример|
|---|---|---|---|
|**Ссылка**|`<a>`|Переход на другую страницу или раздел|`<a href="page.html">Открыть</a>`|
|**Кнопка**|`<button>`|Выполняет действие (например, отправку формы, запуск JS)|`<button>Отправить</button>`|

🧭 Главное различие:

- `<a>` → **навигация** (переход);
    
- `<button>` → **действие** (интерактив).
