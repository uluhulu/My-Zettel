1.      Создание модулей. Как происходит поиск модулей?
Модуль - это файл с расширением .py, содержащий функции, классы и переменные. Пример создания модуля 

```
# mymodule.py
def greet(name):
    return f"Hello, {name}!"

PI = 3.1415
```

Поиск модулей в Python происходит в следующем порядке:
- Текущая директория
- Директории, перечисленные в переменной окружения PYTHONPATH
- Стандартные директории Python (site-packages)

1.      Как происходит компиляция модулей на Python?
- Python - интерпретируемый язык, но на самом деле выполняется в несколько этапов
- Лексический и синтексический разбор : исходный код преобразуется в абстрактное синтаксическое дерево
- Компиляция в байт-код : AST компилируется в байт код
- Выполнение байт-кода интерпретатором CPython.

1.      Назовите стандартные модули Python. .
Стандартные модули - это встроенные библиотеки , которые идут с Python. Некоторые популярные :

random - генерации случайных чисел
os - работа с операционной системой

datetime - работа с датой и временем

collections - дополнительные структуры данных

2.      Опишите использование функции dir().
dir() показывает список атрибутов и методов объекта или модуля.
```
import math
print(dir(math))  # выведет все функции и константы модуля math

class MyClass:
    x = 5
    def hello(self):
        return "Hi"
        
print(dir(MyClass))  # ['__module__', 'x', 'hello', ...]

```

3.      Как объявить класс?. Как управлять  атрибутами и методами класса ?
Класс объявляется через ключевое слово `class`:
- **Атрибуты класса** — общие для всех экземпляров (`species`).
    
- **Атрибуты экземпляра** — уникальны для каждого объекта (`name`, `age`).
    
- Методы управляют поведением объекта.

4.      Что такое множественное наследование?
Множественное наследование — это когда класс наследует свойства и методы сразу нескольких родительских классов.

Как заимствовать свойства и методы у родительского класса

```
class Child(Father, Mother):
    def skills(self):
        parent_skills = super().skills()  # вызывает метод первого родителя
        return f"{parent_skills} and Sports"

c = Child()
print(c.skills())  # Gardening and Sports

```
