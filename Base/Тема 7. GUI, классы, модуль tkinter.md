1.      Создание модулей. Как происходит поиск модулей?
Модуль - это файл с расширением .py, содержащий функции, классы и переменные. Пример создания модуля 

```
# mymodule.py
def greet(name):
    return f"Hello, {name}!"

PI = 3.1415
```

Поиск модулей в Python происходит в следующем порядке:
- Текущая директория
- Директории, перечисленные в переменной окружения PYTHONPATH
- Стандартные директории Python (site-packages)

1.      Как происходит компиляция модулей на Python?
- Python - интерпретируемый язык, но на самом деле выполняется в несколько этапов
- Лексический и синтексический разбор : исходный код преобразуется в абстрактное синтаксическое дерево
- Компиляция в байт-код : AST компилируется в байт код
- Выполнение байт-кода интерпретатором CPython.

1.      Назовите стандартные модули Python. .
Стандартные модули - это встроенные библиотеки , которые идут с Python. Некоторые популярные :
math - математические функции
random - генерации случайных чисел
os - работа с операционной системой
sys - системные функции и параметры интерпритатора
datetime - работа с датой и временем
json - работа с json
re - регулярные выражения
collections - дополнительные структуры данных
