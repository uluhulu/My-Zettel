Условный экспорт — мощная возможность языка Dart, которая позволяет подключать разные реализации в зависимости от платформы, на которой выполняется код.

```
export 'db_executor_stub.dart'
    if (dart.library.ffi) 'db_executor_native.dart'
    if (dart.library.html) 'db_executor_web.dart';
```

- **`export`**: Оператор `export` экспортирует файл, чтобы другие файлы, импортирующие этот, получили доступ к его API.
- **`if (dart.library.ffi)`**: Если доступна библиотека `dart:ffi` (обычно это означает запуск на нативной платформе — Android, iOS, macOS или Linux), то подключается `'db_executor_native.dart'`.
- **`if (dart.library.html)`**: Если доступна библиотека `dart:html` (что указывает на выполнение в браузере), то подключается `'db_executor_web.dart'`.
- **Резервный вариант (`'db_executor_stub.dart'`)**: Если ни одна из этих библиотек не доступна, используется заглушка — `db_executor_stub.dart`.

Такой подход нужен, когда:

- Вы пишете пакет Dart, который должен работать на нескольких платформах (например, мобильных, веб, настольных).
    
- Для каждой платформы требуется своя реализация функций — например, для доступа к базе данных, файловой системе или нативным API.

### Пример использования

Допустим, вы разрабатываете исполнителя запросов к базе данных:

- На мобильных устройствах и десктопах используете `dart:ffi` для работы с SQLite через нативные биндинги.
    
- В вебе используете IndexedDB.
    
- На других платформах `db_executor_stub.dart` может, например, выбрасывать исключение или просто ничего не делать (заглушка).
