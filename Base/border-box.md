Это CSS-правило `* { box-sizing: border-box; }` - одно из самых важных и полезных правил в современной веб-разработке. Оно применяется ко всем элементам на странице (селектор `*` означает "все элементы").

## Что делает `box-sizing: border-box`?

Это свойство изменяет модель расчета размеров элементов:

### По умолчанию (`content-box`):
Общая ширина = width + padding + border
### С `border-box`:
Общая ширина = width (включает padding и border)
