Frontend - это приложение с которым напрямую взаимодействует пользователь. В контексте веб - приложение, которое запускается в браузере. 

Для разработки используется 3 языка программирования : HTML, CSS, JavaScript

C помощью HTML строиться каркас приложения. С помощью HTML описываются отдельные страницы : все эти страницы связаны ссылками. 

CSS - описывает внешний вид приложения. С помощью него можно задать анимации, размеры, цвета, позиционирование и т. д. 

JavaScript - добавляет логику и интерактивность.
