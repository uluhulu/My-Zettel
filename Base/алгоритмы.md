# Класс Node

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left: Optional['Node'] = None
        self.right: Optional['Node'] = None
        self.parent: Optional['Node'] = None

    def __repr__(self):
        return f"Node({self.value})"
```

- `class Node:` — объявление класса узла дерева.
    
- `def __init__(self, value):` — конструктор, принимает значение узла.
    
- `self.value = value` — сохраняет полезную нагрузку (значение) в узле.
    
- `self.left: Optional['Node'] = None` — ссылка на левого ребёнка; изначально `None`.
    
- `self.right: Optional['Node'] = None` — ссылка на правого ребёнка; изначально `None`.
    
- `self.parent: Optional['Node'] = None` — ссылка на родителя; полезна при удалении и трансплантации.
    
- `def __repr__(self):` — строковое представление узла для отладки; возвращает `Node(значение)`.
    

# Класс BST (обёртка для дерева и методов)

```python
class BST:
    def __init__(self):
        self.root: Optional[Node] = None
```

- `class BST:` — класс, реализующий двоичное дерево поиска и связанные операции.
    
- `def __init__(self):` — конструктор BST.
    
- `self.root: Optional[Node] = None` — корень дерева; пустой при создании.
    

## Вставка (insert)

```python
    def insert(self, value) -> Node:
        node = Node(value)
        y = None
        x = self.root
        while x is not None:
            y = x
            if node.value < x.value:
                x = x.left
            else:
                x = x.right
        node.parent = y
        if y is None:
            self.root = node
        elif node.value < y.value:
            y.left = node
        else:
            y.right = node

        # после изменения отрисовываем
        self.draw_tree(title=f"Insert {value}")
        return node
```

- `def insert(self, value) -> Node:` — метод вставки значения в BST; возвращает созданный узел.
    
- `node = Node(value)` — создаём новый узел с `value`.
    
- `y = None` — вспомогательная переменная для родителя узла; начально `None`.
    
- `x = self.root` — начинаем обход с корня; `x` — текущий узел в поиске места.
    
- `while x is not None:` — пока не дойдём до пустого места:
    
    - `y = x` — сохраняем текущий как потенциального родителя.
        
    - `if node.value < x.value: x = x.left` — идём влево, если новое значение меньше.
        
    - `else: x = x.right` — иначе — вправо.
        
- После цикла `x` стал `None`, `y` — узел, под который нужно вставить `node`.
    
- `node.parent = y` — привязываем родителя к новому узлу.
    
- `if y is None: self.root = node` — если `y` всё ещё `None`, дерево было пусто → новый узел становится корнем.
    
- `elif node.value < y.value: y.left = node` — если значение меньше значения `y` — вставляем как левый ребёнок.
    
- `else: y.right = node` — иначе вставляем правым ребёнком.
    
- Комментарий `# после изменения отрисовываем` — визуальный отклик.
    
- `self.draw_tree(title=f"Insert {value}")` — вызывает функцию отрисовки дерева с подписью.
    
- `return node` — возвращаем ссылку на вставленный узел.
    

## Поиск (find)

```python
    def find(self, value) -> Optional[Node]:
        x = self.root
        while x:
            if value == x.value:
                return x
            elif value < x.value:
                x = x.left
            else:
                x = x.right
        return None
```

- `def find(self, value) -> Optional[Node]:` — итеративный поиск значения; возвращает узел или `None`.
    
- `x = self.root` — стартуем с корня.
    
- `while x:` — пока есть текущий узел:
    
    - `if value == x.value: return x` — нашли, возвращаем узел.
        
    - `elif value < x.value: x = x.left` — идём влево, если искомое меньше.
        
    - `else: x = x.right` — иначе вправо.
        
- Если цикл завершился — не нашли → `return None`.
    

## Вспомогательная функция трансплантации (_transplant)

```python
    def _transplant(self, u: Node, v: Optional[Node]):
        if u.parent is None:
            self.root = v
        elif u is u.parent.left:
            u.parent.left = v
        else:
            u.parent.right = v
        if v:
            v.parent = u.parent
```

- `def _transplant(self, u: Node, v: Optional[Node]):` — заменяет поддерево с корнем `u` поддеревом с корнем `v`.
    
- `if u.parent is None: self.root = v` — если `u` был корнем, корень теперь `v`.
    
- `elif u is u.parent.left: u.parent.left = v` — если `u` — левый ребёнок, то левый ребёнок родителя становится `v`.
    
- `else: u.parent.right = v` — иначе правый ребёнок родителя становится `v`.
    
- `if v: v.parent = u.parent` — если `v` не `None`, обновляем для `v` ссылку на родителя.
    

Эта функция упрощает удаление: она заменяет один фрагмент дерева другим, корректно поддерживая ссылки parent.

## Поиск минимума в поддереве (_minimum)

```python
    def _minimum(self, x: Node) -> Node:
        while x.left:
            x = x.left
        return x
```

- `def _minimum(self, x: Node) -> Node:` — возвращает узел с минимальным значением в поддереве, корнем которого `x`.
    
- `while x.left: x = x.left` — идём слева до конца.
    
- `return x` — минимальный элемент.
    

## Удаление (delete)

```python
    def delete(self, value) -> bool:
        node = self.find(value)
        if node is None:
            print(f"Delete {value}: not found")
            return False

        # стандартный BST delete
        if node.left is None:
            self._transplant(node, node.right)
        elif node.right is None:
            self._transplant(node, node.left)
        else:
            y = self._minimum(node.right)
            if y.parent is not node:
                self._transplant(y, y.right)
                y.right = node.right
                if y.right:
                    y.right.parent = y
            self._transplant(node, y)
            y.left = node.left
            if y.left:
                y.left.parent = y

        # после изменения отрисовываем
        self.draw_tree(title=f"Delete {value}")
        return True
```

- `def delete(self, value) -> bool:` — удаляет узел со значением `value`; возвращает `True`, если удаление выполнено, `False` если нет.
    
- `node = self.find(value)` — пытаемся найти узел.
    
- `if node is None:` — если не найден: печатаем сообщение и возвращаем `False`.
    
- Далее стандартные случаи удаления в BST:
    
    - `if node.left is None:` — если нет левого ребёнка, заменяем `node` на `node.right` (даже если `node.right` `None`).
        
        - `self._transplant(node, node.right)`
            
    - `elif node.right is None:` — если нет правого ребёнка, заменяем на `node.left`.
        
        - `self._transplant(node, node.left)`
            
    - `else:` — если оба ребёнка есть:
        
        - `y = self._minimum(node.right)` — находим преемника (минимум правого поддерева).
            
        - `if y.parent is not node:` — если преемник не является прямым правым ребёнком `node`:
            
            - `self._transplant(y, y.right)` — заменяем `y` на его правого ребёнка (у `y` нет левого ребёнка по определению минимума).
                
            - `y.right = node.right` — перенастраиваем правую ссылку `y` на правое поддерево `node`.
                
            - `if y.right: y.right.parent = y` — корректируем родителя правого поддерева.
                
        - `self._transplant(node, y)` — заменяем `node` на `y` (преемника).
            
        - `y.left = node.left` — привязываем левое поддерево старого `node` к `y`.
            
        - `if y.left: y.left.parent = y` — корректируем родителя левого поддерева.
            
- `self.draw_tree(title=f"Delete {value}")` — отрисовываем дерево после удаления.
    
- `return True` — успешное удаление.
    

# Traversals (обходы)

## BFS iterative (уровневый, через очередь)

```python
    def bfs_iterative(self) -> List:
        if self.root is None:
            return []
        q = deque([self.root])
        res = []
        while q:
            node = q.popleft()
            res.append(node.value)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        return res
```

- Если дерево пустое — возвращаем пустой список.
    
- Инициализируем очередь `q` корнем.
    
- `res` — список значений в порядке обхода.
    
- Пока очередь непуста: берём узел слева (`popleft`), добавляем его значение в `res`, и при наличии детей — добавляем их в очередь слева-направо.
    
- Возвращаем список значений по уровням.
    

## BFS recursive (по уровням, через высоту)

```python
    def _height(self, node: Optional[Node]) -> int:
        if node is None:
            return 0
        return 1 + max(self._height(node.left), self._height(node.right))

    def _gather_level(self, node: Optional[Node], level: int, out: List):
        if node is None:
            return
        if level == 1:
            out.append(node.value)
        else:
            self._gather_level(node.left, level - 1, out)
            self._gather_level(node.right, level - 1, out)

    def bfs_recursive(self) -> List:
        h = self._height(self.root)
        res = []
        for lvl in range(1, h + 1):
            self._gather_level(self.root, lvl, res)
        return res
```

- `_height` — рекурсивно вычисляет высоту поддерева (0 для `None`).
    
- `_gather_level(node, level, out)` — добавляет в `out` все узлы на данном `level` (1 — текущий узел).
    
- `bfs_recursive` — поочерёдно вызывает `_gather_level` для уровней от 1 до `h`. Это рекурсивный способ обхода уровнями; менее эффективен, но демонстрирует рекурсивный подход.
    

## DFS recursive: preorder, inorder, postorder

```python
    def _preorder_rec(self, node: Optional[Node], out: List):
        if not node:
            return
        out.append(node.value)
        self._preorder_rec(node.left, out)
        self._preorder_rec(node.right, out)

    def _inorder_rec(self, node: Optional[Node], out: List):
        if not node:
            return
        self._inorder_rec(node.left, out)
        out.append(node.value)
        self._inorder_rec(node.right, out)

    def _postorder_rec(self, node: Optional[Node], out: List):
        if not node:
            return
        self._postorder_rec(node.left, out)
        self._postorder_rec(node.right, out)
        out.append(node.value)

    def preorder_recursive(self) -> List:
        out = []
        self._preorder_rec(self.root, out)
        return out

    def inorder_recursive(self) -> List:
        out = []
        self._inorder_rec(self.root, out)
        return out

    def postorder_recursive(self) -> List:
        out = []
        self._postorder_rec(self.root, out)
        return out
```

- Три рекурсивные функции для каждого варианта DFS:
    
    - Preorder: посетить узел, затем левое, затем правое поддерево.
        
    - Inorder: левое, узел, правое — для BST даёт отсортированный порядок.
        
    - Postorder: левое, правое, узел.
        
- Каждая публичная функция создаёт `out` и вызывает соответствующую рекурсивную реализацию с корнем.
    

## DFS iterative (иттеративные аналоги)

```python
    def preorder_iterative(self) -> List:
        if not self.root:
            return []
        stack = [self.root]
        out = []
        while stack:
            node = stack.pop()
            out.append(node.value)
            # push right first so left is processed first
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
        return out
```

- Preorder итеративно: используем стек; вытаскиваем текущий, добавляем значение, затем пушим правого потом левого (правый первым, чтобы левый обрабатывался раньше).
    

```python
    def inorder_iterative(self) -> List:
        out = []
        stack = []
        curr = self.root
        while stack or curr:
            while curr:
                stack.append(curr)
                curr = curr.left
            curr = stack.pop()
            out.append(curr.value)
            curr = curr.right
        return out
```

- Inorder итеративно: идём влево, добавляя узлы в стек; затем обрабатываем вершину стека и идём направо.
    

```python
    def postorder_iterative(self) -> List:
        # two-stack method
        if not self.root:
            return []
        s1 = [self.root]
        s2 = []
        while s1:
            node = s1.pop()
            s2.append(node)
            if node.left:
                s1.append(node.left)
            if node.right:
                s1.append(node.right)
        return [n.value for n in reversed(s2)]
```

- Postorder итеративно реализовано через два стека: первый стек для обхода, второй собирает узлы в порядке root-right-left, потом переворачиваем `s2` чтобы получить левое-правое-root.
    

# Визуализация дерева (matplotlib)

## Вычисление позиций

```python
    def _compute_positions(self) -> Tuple[dict, dict]:
        positions = {}
        labels = {}
        x_counter = [0]  # mutable counter

        def dfs_pos(node: Optional[Node], depth: int):
            if node is None:
                return
            dfs_pos(node.left, depth + 1)
            x = x_counter[0]
            positions[node] = (x, -depth)  # y negative so root on top in plot
            labels[node] = str(node.value)
            x_counter[0] += 1
            dfs_pos(node.right, depth + 1)

        dfs_pos(self.root, 0)
        return positions, labels
```

- `_compute_positions` возвращает `positions` (mapping node -> (x,y)) и `labels` (node -> строка).
    
- `x_counter = [0]` — используется как счётчик, обёрнут в список, чтобы была изменяемая замкнутая переменная в `dfs_pos`.
    
- `dfs_pos` — рекурсивный inorder обход:
    
    - сначала посещаем левое поддерево (чтобы у левых узлов был меньший x),
        
    - затем назначаем текущую x позицию `x_counter[0]` и y = `-depth` (отрицательная, чтобы root был сверху при рисовании),
        
    - увеличиваем `x_counter`,
        
    - затем идём вправо.
        
- Такой способ гарантирует аккуратное горизонтальное расположение без перекрытия.
    

## Отрисовка

```python
    def draw_tree(self, title: str = "BST"):
        positions, labels = self._compute_positions()
        if not positions:
            # пустое дерево
            plt.figure(figsize=(6, 3))
            plt.title(f"{title} (empty)")
            plt.axis('off')
            plt.show()
            return

        fig, ax = plt.subplots(figsize=(max(6, len(positions)), 4))
        ax.set_title(title)
        ax.axis('off')

        # Draw edges
        for node, (x, y) in positions.items():
            if node.left:
                x2, y2 = positions[node.left]
                ax.plot([x, x2], [y, y2], linewidth=1, zorder=1)
            if node.right:
                x2, y2 = positions[node.right]
                ax.plot([x, x2], [y, y2], linewidth=1, zorder=1)

        # Draw nodes
        for node, (x, y) in positions.items():
            circle = plt.Circle((x, y), 0.2, fill=True, color='white', ec='black', zorder=2)
            ax.add_patch(circle)
            ax.text(x, y, labels[node], horizontalalignment='center',
                    verticalalignment='center', zorder=3, fontsize=9)

        # adjust limits
        xs = [p[0] for p in positions.values()]
        ys = [p[1] for p in positions.values()]
        margin_x = 1
        margin_y = 1
        ax.set_xlim(min(xs) - margin_x, max(xs) + margin_x)
        ax.set_ylim(min(ys) - margin_y, max(ys) + margin_y)
        plt.show()
```

- `positions, labels = self._compute_positions()` — получаем координаты и подписи.
    
- Если `positions` пуст — рисуем пустой холст с пометкой `(empty)` и выходим.
    
- `fig, ax = plt.subplots(figsize=(max(6, len(positions)), 4))` — создаём фигуру, ширина зависит от числа узлов (чтобы не сжималось).
    
- `ax.set_title(title)` — заголовок рисунка.
    
- `ax.axis('off')` — убираем оси для чистоты рисунка.
    
- Блок `# Draw edges`: проходим по всем узлам; если есть левый/правый ребёнок — рисуем линию от родителя к ребёнку (координаты берём из `positions`).
    
- Блок `# Draw nodes`: для каждого узла рисуем круг (`plt.Circle`) и текст внутри круга `ax.text`.
    
    - `zorder` контролирует порядок отрисовки (ребра — нижний слой, круги — выше, текст — выше всего).
        
- В конце вычисляем минимумы/максимумы по осям, добавляем небольшой `margin` и выставляем пределы `ax.set_xlim`/`ax.set_ylim`.
    
- `plt.show()` — отображаем окно/картинку (в Jupyter — inline).

- `tree = BST()` — создаём пустое дерево.
    
- `ops = [...]` — список операций (только вставки в этом примере).
    
- Цикл `for op, val in ops:` — выполняем вставки; при каждой вставке внутри `insert` рисуется дерево.
    
- Печатаем все обходы после всех вставок.
    
- `dels = [20, 30, 50]` — список удалений: сначала лист (20), затем узел с одним ребёнком (30), затем корень (50). Это демонстрирует все классы удаления.
    
- Цикл удаления: `ok = tree.delete(d)` — если удаление прошло, `delete` также перерисует дерево.
    
- В конце печатаем финальные обходы.
    
- `if __name__ == "__main__": demo()` — стандартный блок: если файл запускается как скрипт, выполняется `demo()`.

# Резюме — ключевые моменты, которые важно понять

- Код реализует **классический BST** с `insert`, `find`, `delete` и поддержкой `parent`-ссылок — это упрощает удаление и трансплантацию.
    
- Обходы реализованы **и рекурсивно, и итеративно** — полезно для обучения и сравнения.
    
- Визуализация: позиции вычисляются через **inorder-проход**, поэтому дерево выглядит аккуратно: левое поддерево слева, правое — справа; уровень отражён по вертикали.
    
- После каждой вставки/удаления автоматически вызывается `draw_tree`, поэтому ты получаешь графический отклик на каждую операцию.
    
- Код читаемый и пригоден как учебный пример; для промышленных задач можно добавить обработку дубликатов, балансировку (AVL/Red-Black), сохранение/загрузку и т.п.
