Исходные данные 
IP- адрес узла 172.16.70.100
Старая маска 255.255.0.0 /16
Новая маска 255.255.240.0 /20

Определяем, сколько бит было одолжено под сети

Старая маска /16 - 16 бит под сети
Новая маска /20 - 20 бит под сети

Значит 20-16 = 4 бита заимствованы из части, отвечающей за хосты. 

**Сколько получилось подсетей ?**

Каждый "одолженный" бит удваивает число возможных комбинаций.

2^4 = 16 подсетей.
- Значит, исходная сеть 172.16.0.0 / 16 теперь разбита на 16 подсетей / 20. 

**Сколько адресов в одной подсети**
Новая маска /20 составляет 32-20 = 12 бит для хостов.

Каждый хост это комбинация этих 12 бит.

2^12 = 4096 адресов в подсети

Но 2 адреса зарезервированы :
- 1 для сети 
- 1 для broadcast
 4096 - 2 = 4094 хоста можно использовать.
