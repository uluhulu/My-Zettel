## Что это делает:

**`Bloc.transformer`** устанавливает **глобальный трансформер событий** для всех BLoC'ов в приложении, который определяет **как обрабатываются множественные события**.

## Что такое `sequential()`:

**`sequential()`** - это трансформер из пакета `bloc_concurrency`, который обрабатывает события **последовательно** (одно за другим).

## Проблема, которую решает:

### **Без трансформера (по умолчанию):**

```
// Пользователь быстро нажимает кнопку "Загрузить"
userBloc.add(LoadUserEvent()); // Событие 1
userBloc.add(LoadUserEvent()); // Событие 2  
userBloc.add(LoadUserEvent()); // Событие 3

// Все три запроса выполняются ПАРАЛЛЕЛЬНО:
// API вызов 1 ┐
// API вызов 2 ├─ Одновременно!
// API вызов 3 ┘

// Результат: состояние может быть непредсказуемым
```
### **С `sequential()` трансформером:**

```
userBloc.add(LoadUserEvent()); // Событие 1
userBloc.add(LoadUserEvent()); // Событие 2
userBloc.add(LoadUserEvent()); // Событие 3

// События обрабатываются ПОСЛЕДОВАТЕЛЬНО:
// API вызов 1 → ждем завершения → API вызов 2 → ждем → API вызов 3
```

## Альтернативные трансформеры:

### **1. `concurrent()` - параллельная обработка:**
```
Bloc.transformer = bloc_concurrency.concurrent();

// Все события обрабатываются одновременно (по умолчанию)
```

### **2. `droppable()` - отбрасывание новых событий:**
```
Bloc.transformer = bloc_concurrency.droppable();

// Если событие уже обрабатывается, новые игнорируются
```
### **3. `restartable()` - перезапуск обработки:**

Bloc.transformer = bloc_concurrency.restartable();

// Новое событие отменяет предыдущее
