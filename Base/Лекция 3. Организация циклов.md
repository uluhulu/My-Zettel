1.      Перечислите операторы цикла.
В python есть два основных оператора цикла :
- for - выполняет код для каждого элемента в последовательности (списке, строке, диапозоне )
- while - повторяет код пока условие истинно

Дополнительно внутри циклов можно использовать: 

- break - досрочно завершает цикл
- continue - пропускает текущую итерацию 
- else - выполняется, если цикл завершился не через break

2.      Что такое оператор for? 
- for - это цикл который проходит по каждому элементу итерируемого объекта 

3.      Что такое  оператор while? 
while - повторяет код пока условие истинно

4.      Как осуществляется завершение цикла? 
	Цикл заканчивается сам:  
	- for - когда закончились элементы последовательности
	- while - когда условие стало ложным 
	Операторы 
	- break - оператор принудительно  останавливает цикл, даже если элементов или условий еще достаточно 
	- return - не только завершает цикл, но завершает всю функцию 
	Если во время выполнения возникает ошибка - цикл тоже заканчивается 
	 Циклы могут иметь else, который выполняется только если цикл завершился естественно, то есть не через break

5.      Что такое оператор pass? 
- pass - оператор заглушка, нужен что бы избежать ошибки синтаксиса в пустых блоках кода

6.      Дайте определение функции. Что такое пространство имен функции? 

**Функция** — это именованный блок кода, который выполняет определённую задачу и может многократно вызываться.
Функця может :
- применять данные 
- выполнять действия
- возвращать результат с помощью return
Пространство имен функции - область, внутри которой существуют имена (переменные ) - созданные в функции.

Локальное простарнство имен - все, что создаётся внутри функции (переменные, параметры) существует только нутрии функции

7.      Как происходит передача параметров?
Когда ты передаешь параметр в функцию, в функцию передается не сам объект, а ссылка на объект, который уже существует в памяти. 

Поведение зависит от того, изменяемый это объект или неизменяемый.

Если объект неизменяемый: 
 - внутри функции ты получишь ссылку на тот же объект, но изменить его нельзя, поэтому любое изменение создает новый объект.

Если объект изменяемый : 
- внутри функции ты получаешь ссылку на тот же объект и можешь изменить его содержимое
