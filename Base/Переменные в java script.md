### Основные типы данных в JavaScript

- **Number** — числовой тип (целые и дробные числа):
    
    ```js
    let age = 25;
    let price = 19.99;
    ```
    
- **String** — строковый тип (текст):
    
    ```js
    let name = "Иван";
    let greeting = 'Привет!';
    ```
    
- **Boolean** — логический тип (true или false):
    
    ```js
    let isActive = true;
    ```
    
- **Undefined** — значение не определено:
    
    ```js
    let data;
    console.log(data); // undefined
    ```
    
- **Null** — пустое или отсутствующее значение:
    
    ```js
    let value = null;
    ```
    
- **Object** — сложный тип данных (объекты, массивы, функции):
    
    ```js
    let user = { name: "Анна", age: 30 };
    let arr = [1, 2, 3];
    ```
    

---

### Переменные

- Объявление переменных:
    
    ```js
    let x = 10;       // изменяемая переменная
    const y = 20;     // константа, нельзя изменить
    var z = 30;       // устаревший способ (лучше не использовать)
    ```
    

---

### Преобразование типов

- В строку:
    
    ```js
    String(123);  // "123"
    ```
    
- В число:
    
    ```js
    Number("456");  // 456
    ```
    
- В логическое:
    
    ```js
    Boolean(0);    // false
    Boolean("text"); // true
    ```
    

---

### Работа с объектами и массивами

- Создание объекта:
    
    ```js
    let person = { name: "Олег", age: 40 };
    console.log(person.name);  // "Олег"
    ```
    
- Создание массива:
    
    ```js
    let fruits = ["яблоко", "банан", "груша"];
    console.log(fruits[1]);  // "банан"
    ```
