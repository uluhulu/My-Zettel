1.   Как осуществляется вывод данных в python?  Как осуществляется Ввод данных? 
- Для вывода информации на экран в Python используется **функция `print()`**.
- `sep` — разделитель между элементами
- `end` — символ, который ставится **в конце строки**
- форматирование с помощью f строк print(f"Меня зовут {name}, мне {age} лет")

- name = input("Введите имя: ")
- Если ты вводишь число, Python всё равно считает это **строкой**.
- Чтобы работать с числами, нужно **преобразовать ввод**: a = int(input("Введите целое число: "))

3.      Что такое списки? Что такое выражения в списках? Как осуществляется использование списков как стеков? Как осуществляется использование списков как очередей? Какие существуют  операции сравнения для списков ? 
- Списки и кортежи это коллекции, обладающие свойством упорядоченности, то есть последовательности
- Списки изменяемы (mutable) класс списка list литерал списка используют квадратные скобки 
- Списки и кортежи реализованы как массив ячеек одинакового размера, в которых хранятся ссылки на объекты-элементы
- В списке могут изменяться как количество ячеек так и адреса объектов, хранящихся в них
- В списке и кортежах могут быть мешаны элементы разных типов, то есть в ячейке может быть ссылка на люой объект
- Что такое выражения в списках (list comprehensions)

4.      Что такое диапазоны? Что такое Кортежи? Перечислите отличие кортежей от словарей. Что такое Словари? [ПК-1, ПК-2]
- Кортежи неизменяемы (immutable), класс кортежа tuple, литерал кортежа использует круглые скобки
- Количество ячеек и адреса объектов, хранящихся в ячейках, для кортежа величина постоянная
- Словарь это ассоциативный массив или хеш, то есть коллекция содержащая пары "ключ : значение". Класс словаря dict.
- Словарь имеет свойства :
- перечислимость
- изменяемость
- Словарь это не последовательность
- Нет операции с фрагментами (slice)
