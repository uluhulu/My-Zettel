## 🌐 1. Что такое сетевая адресация

**Сетевая адресация** — это система, с помощью которой каждому устройству в сети присваивается **уникальный адрес**, чтобы данные могли передаваться от одного узла к другому.

В компьютерных сетях используются **два уровня адресации:**

1. **Физический (канальный уровень)** — **MAC-адрес**
    
2. **Логический (сетевой уровень)** — **IP-адрес (IPv4 / IPv6)**
    

---

## 🧩 2. MAC-адрес (Media Access Control)

- **Назначение:** уникальный физический адрес сетевого адаптера (сети, Wi-Fi-карты и т.п.).
    
- **Формат:** 48 бит (6 байт), обычно записывается в шестнадцатеричном виде:
    
    ```
    00:1A:2B:3C:4D:5E
    ```
    
- **Пример:** `F0-9E-4A-12-34-56` или `F0:9E:4A:12:34:56`
    
- **Особенности:**
    
    - Задаётся производителем оборудования.
        
    - Уникален для каждого устройства.
        
    - Используется **внутри локальной сети (LAN)**.
        

---

## 🌍 3. IPv4-адрес

- **Длина:** 32 бита (4 байта).
    
- **Формат:** четыре числа от 0 до 255, разделённые точками.
    
    ```
    192.168.0.15
    ```
    
- **Количество адресов:** около 4,3 миллиарда.
    
- **Типы адресов:**
    
    - **Публичные (в Интернете)** — видимы во внешней сети.
        
    - **Приватные (внутренние):**
        
        ```
        10.0.0.0 – 10.255.255.255  
        172.16.0.0 – 172.31.255.255  
        192.168.0.0 – 192.168.255.255
        ```
        
- **Запись с маской:**  
    Например, `192.168.1.10/24` — означает маску 255.255.255.0
    

---

## 🌐 4. IPv6-адрес

- **Длина:** 128 бит.
    
- **Формат:** 8 групп по 16 бит, разделённые двоеточиями.
    
    ```
    2001:0db8:85a3:0000:0000:8a2e:0370:7334
    ```
    
- **Количество адресов:** колоссальное — ≈ 3,4×10³⁸
    
- **Причина появления:** нехватка IPv4-адресов.
    

---

## ✂️ 5. Правила сокращения IPv6

Чтобы IPv6-адреса не выглядели слишком длинными, есть **правила упрощения записи:**

### 🔸 Правило 1. Убираем ведущие нули

В каждой группе можно опускать нули **в начале**, но не в середине.

```
2001:0db8:0000:0042:0000:0000:0000:08a2  
↓  
2001:db8:0:42:0:0:0:8a2
```

---

### 🔸 Правило 2. Заменяем подряд идущие нули на «::»

Один раз в адресе можно заменить **одну последовательность** нулевых групп на `::`.

```
2001:db8:0:42:0:0:0:8a2  
↓  
2001:db8:0:42::8a2
```

> ⚠️ «::» можно использовать **только один раз** в адресе, иначе будет неоднозначность.

---

### 🔸 Примеры:

|Полная запись|Сокращённая форма|
|---|---|
|`2001:0db8:0000:0000:0000:0000:0000:0001`|`2001:db8::1`|
|`fe80:0000:0000:0000:0202:b3ff:fe1e:8329`|`fe80::202:b3ff:fe1e:8329`|
|`2001:0db8:0000:0042:0000:8a2e:0370:7334`|`2001:db8:0:42:0:8a2e:370:7334`|

---

## 🔢 6. Отображение IPv4-адресов в IPv6 (IPv4-mapped IPv6)

Чтобы IPv4-устройства могли работать в IPv6-сетях, применяется **специальная форма:**

```
::ffff:192.168.1.10
```

Это IPv6-запись, представляющая старый IPv4-адрес.

---

## 🔗 7. Сравнение MAC, IPv4 и IPv6

|Параметр|MAC|IPv4|IPv6|
|---|---|---|---|
|Уровень|Канальный|Сетевой|Сетевой|
|Длина|48 бит|32 бита|128 бит|
|Формат|6 пар шестнадцатеричных чисел|4 десятичных числа (0–255)|8 групп по 16 бит|
|Пример|00:1A:2B:3C:4D:5E|192.168.1.10|2001:db8::1|
|Кем задаётся|Производителем|Администратором / DHCP|Администратором / DHCPv6|
|Область действия|Локальная сеть|Локальная и глобальная|Глобальная|
|Количество адресов|~2⁴⁸|~4,3 млрд|~3,4×10³⁸|
