**`StringBuffer`** — это класс в языке программирования **Java**, который используется для работы со строками, когда нужно часто **изменять** их содержимое.

---

### Почему именно StringBuffer?

В Java строка (`String`) **неизменяема** (immutable). Это значит, что когда ты меняешь строку, на самом деле создаётся новая строка в памяти. Если много раз изменять строку, это неэффективно.

**`StringBuffer`** позволяет **изменять строку без создания новых объектов**, что намного быстрее и эффективнее при большом количестве изменений.

---

### Основные особенности `StringBuffer`:

- **Изменяемый (mutable)** — можно добавлять, удалять, изменять символы без создания новых объектов.
    
- **Потокобезопасный (thread-safe)** — методы синхронизированы, можно использовать в многопоточных программах без проблем с данными.
    
- Есть похожий класс **`StringBuilder`**, который тоже изменяемый, но **не потокобезопасный**, зато быстрее в однопоточных приложениях.
    

---

### Пример использования:

```java
StringBuffer sb = new StringBuffer("Привет");
sb.append(" мир");  // Добавляем текст
System.out.println(sb);  // Выведет: Привет мир
```

---

### Когда использовать?

- Когда нужно **много раз изменять строку** (например, в цикле).
    
- Если программа работает с потоками — лучше `StringBuffer`.
    
- Если однопоточная — лучше `StringBuilder` (быстрее).
