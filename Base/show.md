## Что такое `show`:

**`show`** - это ключевое слово для **селективного импорта** в Dart. Оно позволяет импортировать только **определенные элементы** из библиотеки, а не всю библиотеку целиком.

## Синтаксис:

import 'package:library_name' show item1, item2, item3
